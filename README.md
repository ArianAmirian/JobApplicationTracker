Projektbeskrivning:

Job Application Tracker är ett konsolprogram i C# som hjälper användaren att
hålla koll på sina jobbansökningar. Man kan lägga till ansökningar, uppdatera
status, filtrera och sortera dem samt se statistik som antal per status och
genomsnittlig svarstid. Projektet visar objektorienterad programmering,
användning av listor och LINQ samt versionshantering med branches och pull
requests på GitHub.

Hur hjälpte LINQ dig att skriva renare kod?

Linq hjälpte mig att skriva renare kod på sättet där jag slipper använda if
satser och skriva betydligt mindre kod än vad som behövs egentligen.
Färre hjälpvariabler och skapa fler kedjor. Hjälpte mig även sätta ihop flera steg
efter varandra som (where) och (orderBy) utan att skriva nya loopar.
